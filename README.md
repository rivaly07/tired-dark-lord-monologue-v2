A 100-word monologue for a fantasy villain who is secretly just very tired. The weariness sits in the voice, the rhythm and the small deflections — a shortened throne so nobody has to climb it, a split scabbard he does not want bleeding on the map — while the scheme, the drowned kingdom and three centuries of planning stay intact. He is still a villain; he is simply out of patience with the paperwork of villainy.

## Run it

Node 22, standard library only, no network. The monologue is a constant in `main.js`.

```sh
MAKEFUN_OUTPUT_DIR=out node main.js && cat out/entry.txt
```

Two runs produce byte-identical output: `sha256sum out/entry.txt out2/entry.txt` matches. 107 words.
